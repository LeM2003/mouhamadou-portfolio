## 2. Tendances design 2026 pour portfolios devs/builders

### Couleurs qui montent
- **Off-white chauds** (cream, bone, paper) à la place du blanc pur
- **Terracotta, rust, ochre, sable** : palette warm earth continue de monter depuis 2024
- **Indigo profond / aubergine** comme alternative au navy fatigué
- **Vert sauge / olive** pour les accents (remplace le mint Tailwind devenu cliché)
- **Mort du néon synthwave** et du gradient violet-rose Stripe-like (c'était 2021-2023)

### Typographie
- Serif modernes variables : **Fraunces** (ton choix, excellent), Migra, PP Editorial New
- Sans-serif néo-grotesque custom : Geist, Inter Display, GT Walsheim, Söhne
- **Mono comme typo de métadonnée** (date, stack, numéro projet) : JetBrains Mono, Berkeley Mono, Geist Mono — **standard absolu en 2026**
- Combo gagnant : **1 serif display + 1 sans neutre + 1 mono**, jamais plus

### Animations / micro-interactions
- **Scroll-driven animations CSS natives** (`animation-timeline: scroll()`) — supportées Chrome/Edge/Safari 17.4+. Gratuit en JS, adopte-les.
- **View Transitions API** pour les transitions entre pages — supportée Next 15+
- **Magnetic cursors** : devenu cliché, éviter sauf usage parcimonieux
- **Smooth scroll Lenis** : encore standard mais respecter `prefers-reduced-motion`
- **Hover projet** = preview animée courte plutôt que zoom statique
- **Cursor follower texte** ("View case →") : encore frais quand bien fait

### Copywriting
- Storytelling court à la première personne > minimal froid > technique pur
- Ton 2026 qui marche = **"confiance tranquille"** : phrases courtes, opinions claires, zéro buzzword IA
- À éviter absolument : "passionate", "results-driven", "I love coding" — tué
- Ce qui fonctionne : *"I build X for Y so they can Z"* — concret, mesurable
- Pour toi : *"I build AI-native products"* > *"AI Product Builder passionate about innovation"*

### Mode sombre
- Toggle clair/sombre = standard 2026, mais **default = clair** pour ton portfolio éditorial chaud
- Stocker la préférence + respecter `prefers-color-scheme`
- Le tout-noir `#000` est mort — préférer warm dark (`#1a1814`, `#14110d`)

### À fuir absolument en 2026
- Hero "Hi, I'm X" avec emoji main qui salue
- Glassmorphism (mort depuis 2023)
- Gradient animé multicolore en background
- Liste de logos "as featured in" si tu n'as pas vraiment été featured
- "Available for hire" sticky avec point vert qui pulse — devenu desperate
- Cartes de projets identiques en grille 3 colonnes — c'est ce que tout le monde fait
- Photos de toi devant ton MacBook
- "Building the future of X with AI" sans démo concrète

## 3. Outils design — comparatif honnête

**Usecase** : 3 variantes UI rapides, sans designer dédié.

### Figma (gratuit)
- **Forces** : standard industrie, plugins, ressources gratuites (Fraunces specimen, palettes), Figma AI génère des wireframes corrects.
- **Faiblesses** : courbe d'apprentissage non triviale, fichier vide = anxiogène.
- **Verdict** : utile uniquement pour explorer la composition (grille, hiérarchie) avant de coder. Skip si tu codes vite — tu perdras du temps à recréer en Tailwind.

### Google Stitch
- **Forces** : génère UI par prompt en français, export Figma/code, gratuit.
- **Faiblesses** : sorties **génériques "SaaS template"**, peu de contrôle fin sur typo/grille, palette souvent fade. **Incapable de produire du "éditorial premium"** sans gros prompt engineering.
- **Verdict** : utile en divergence "à quoi ressemble une section témoignages magazine ?" — jamais source de vérité visuelle. Outil de brainstorm, pas de finalisation.

### Claude Artifacts
- **Forces** : génère React + Tailwind testable, itère par conversation, comprend les contraintes éditoriales en français, comparer 3 variantes en 5 prompts.
- **Faiblesses** : pas de canvas WYSIWYG, styles parfois trop "shadcn par défaut" sans précision.
- **Verdict** : **probablement le meilleur outil pour ton workflow**. Tu codes déjà Next/Tailwind, output directement réutilisable. Pour chaque section (hero, projets, à propos), génère 3 variantes en Artifacts → choisis → colle dans le repo → affine.

### Code direct (Tailwind + Next.js)
- **Forces** : pas de friction outil → code, contrôle total, perf vraie.
- **Faiblesses** : tendance à converger trop vite, manque de divergence créative.
- **Verdict** : ta zone de confort, mais **piège** — tu vas livrer "joli mais convenu". À utiliser après une phase de divergence.

### Stack idéal recommandé
1. **Moodboard rapide** (30 min) : savee.it ou cosmos.so
2. **Divergence UI** : Claude Artifacts → 3 variantes par section
3. **Finalisation** : code direct Next.js + Tailwind
4. Figma uniquement pour dessiner ta grille éditoriale (1 seule fois)
5. Stitch : 20 min de test puis oublie si pas concluant

## 4. 5 recommandations actionnables — de "joli" à "mémorable"

### #1 — Remplace le hero classique par un manifeste court
**Où** : hero, au-dessus de la ligne de flottaison.
**Quoi** : 1 phrase opinion forte. Pas "Full Stack Developer & AI Builder". Plutôt : *"Je conçois des produits où l'IA est une décision d'architecture, pas un add-on marketing."* + sous-texte 3 lignes max + 2 CTA (Voir les projets / Discuter).
**Pourquoi** : un hero générique = -10s d'attention. Une opinion = +30s, et tu filtres déjà tes clients.

### #2 — Transforme tes case studies en récits structurés
**Où** : pages projet individuelles (`/projets/01-olele`, etc.).
**Quoi** : structure imposée — `Contexte` (2 lignes) → `Décision technique clé` (1 paragraphe + schéma ou snippet) → `Compromis assumés` (ce que tu n'as PAS fait et pourquoi) → `Résultat chiffré` (3 metrics max).
**Pourquoi** : 95% des portfolios devs montrent "ce que j'ai fait". Toi montre **comment je décide**. C'est ce qui distingue un builder d'un exécutant — et ce qu'un Master IA est censé apporter.

### #3 — Ajoute une page `/maintenant`
**Où** : nav principale, à côté de `À propos`.
**Quoi** : page courte mise à jour mensuellement — projet en cours, ce que tu apprends, ce que tu lis, où tu es. Pattern Derek Sivers, signature builder sérieux.
**Pourquoi** : prouve que ton site est vivant, pas un CV figé. Un recruteur qui revient 2 mois plus tard et voit la page bouger → confiance immédiate.

### #4 — Bilingue FR/EN avec switch typographique subtil
**Où** : header + URL (`/fr` / `/en`).
**Quoi** : switch `FR / EN` en mono (jamais de drapeaux). Bonus signature : les nombres/dates restent en mono dans les deux langues, mais le **ton change vraiment** (FR plus chaleureux, EN plus direct — pas une simple traduction).
**Pourquoi** : ton positionnement triple (Dakar local + freelance international + CDI) exige ce switch.

### #5 — UNE seule signature visuelle mémorable, pas dix
**Où** : un seul endroit, à choisir.
**Quoi** : une seule chose qu'on retient. Exemples crédibles :
- Filet terracotta horizontal animé qui se dessine au scroll entre sections (1 ligne, jamais plus)
- Numérotation projet géante en serif `01` `02` `03` qui dépasse la grille (cassure éditoriale magazine)
- Toggle FR/EN qui transforme aussi la couleur d'accent (indigo en EN, terracotta en FR)
- Curseur custom uniquement sur les titres (pas partout, sinon cliché)

**Pourquoi** : portfolio mémorable = 1 détail dont on parle, pas 10 effets. *"Ah oui le mec avec le 01 02 03 énorme en orange"* > *"Ah oui le mec avec plein d'animations"*.

## Verdict global sur ta direction

Direction "éditorial premium palette sable/terracotta/indigo + Fraunces + projets numérotés" : **bonne direction, à condition d'éviter trois pièges**.

1. **Piège folklore (déjà évité)** : pas de wax, masques, baobabs. Tu l'as compris.
2. **Piège du template magazine** : la combinaison warm + serif est devenue assez courante (Olivia Ng, Maxime Bonhomme, mille studios). Sans signature visuelle forte (point #5), tu seras "encore un portfolio éditorial sympa". Pas mémorable.
3. **Piège dev/design** : un portfolio éditorial premium qui ne prouve pas la tech = tu passes pour un designer. Tu DOIS avoir au moins 1 démo interactive live (style Rauno) qui dit "ce mec code, vraiment".

**Verdict** : direction validée à **70%**. Les 30% restants sont dans l'**exécution de la signature visuelle** et la **preuve de tech via démos in-page**. Sans ces deux, joli mais oubliable.
