## 💎 Mes 5 angles de différenciation

### 1. **Du concret en production, vite**
Je couvre tout le cycle d'un produit web : conception, dev, déploiement, monitoring. MVPs en quelques semaines, code propre, déployé, mesuré. Pas 3 mois de specs avant la première ligne de code.

### 2. **L'IA, je la maîtrise comme produit**
J'intègre LLMs, RAG, automatisations dans tes produits — avec la compréhension technique d'un Master Data Science/IA en cours. Pas juste "appeler une API OpenAI" : je sais ce qui va coûter cher en tokens, ce qui peut halluciner, ce qui scale.

### 3. **Basé à Dakar, fuseau EU-friendly**
Pour les clients EU/US : sans décalage horaire bloquant, communication fluide. Pour les clients africains : sur place, langue commune, connaissance du marché local.

### 4. **Je shippe en vrai**
Olèle Systems (LMS en prod, Vercel), Personal OS V2 (utilisé quotidiennement), MuslimApp (PWA gratuite déployée). Pas de "j'ai fait des tutos", j'ai du **code en production qui tourne pour de vrais utilisateurs**.

### 5. **Polyvalent, full-cycle**
TS, JS, Python, PHP. Front, back, base de données, déploiement. Je gère seul tout le cycle d'un produit — assez autonome pour livrer un MVP, assez technique pour rejoindre une équipe sénior.
